# Tiari 🎬

鑑賞した映画を [tiermaker.com](https://tiermaker.com/) のように、ポスター＋タイトル付きでドラッグ&ドロップしながらランク付けできるツールです。ビルド不要・完全ブラウザ完結で、データは自動的にブラウザ内（localStorage）に保存されます。

## 使い方

### 1. 起動する

**映画の検索を使うため、付属のサーバーを起動してください**（Filmarks を代理取得するために必要です）。

```bash
cd TierListMaker
python3 server.py
# ブラウザで http://localhost:8000 を開く
```

> 追加ライブラリのインストールは不要です（Python 3 標準ライブラリのみ）。ポート変更は `python3 server.py 8080` のように指定します。
>
> 検索機能を使わず手動追加だけで良ければ、`index.html` を直接ダブルクリックで開くだけでも動作します。

サーバーは既定で**同じネットワーク内の他端末からも到達可能**（`0.0.0.0` で待受け）です。起動すると、このMacのURL・自宅Wi-Fi内URL・（Tailscale導入時は）外出先用の案内が表示されます。ローカル専用に戻したい場合は `HOST=127.0.0.1 python3 server.py` としてください。

### スマホで使う（自宅Wi-Fi内 / 外出先）

映画の検索・ポスター取得はMac上の `server.py` が担うため、スマホからはその**サーバーに届く経路**が必要です。

**A. 自宅Wi-Fi内だけで使う（最も簡単）**

1. Mac で `python3 server.py` を起動。
2. スマホを**同じWi-Fi**につなぎ、起動時に表示される `http://<MacのIP>:8000` を開く。

**B. 外出先からも使う（Tailscale 推奨・安全）**

自分の端末だけがつながる仮想ネットワーク（VPN）で、公開せず安全にアクセスできます。

1. Mac とスマホの両方に [Tailscale](https://tailscale.com/) を入れ、**同じアカウントでログイン**。
2. Mac で `python3 server.py` を起動（起動ログに Tailscale 用の案内が出ます）。
3. かんたん接続（HTTP）: スマホで `http://<TailscaleのIP>:8000` を開く。
4. **アプリ化（ホーム画面に追加）したい場合**は HTTPS が必要です。Mac の別ターミナルで次を実行：

   ```bash
   tailscale serve --bg 8000
   ```

   表示される `https://<マシン名>.ts.net/` をスマホで開き、共有メニューから **「ホーム画面に追加」** を選ぶと、全画面のアプリとして使えます（オフラインでも直近の画面を表示可能）。

> データ（Tier List）は端末ごとにブラウザ内へ保存されます。手動で移したいときは **💾 保存 →ファイル(.json)** と **📂 開く** が使えますが、下記の**アカウント機能を使うと自動で端末間同期**できます。

### どこからでも使う（無料・クラウド公開）

Mac を起動していなくても、URL ひとつでスマホ・会社PCなどから使えます。**Render（無料サーバー）でアプリを動かし、データ（アカウント・Tier List）は GitHub の非公開リポジトリに保存**します。費用はかかりません。

1. **GitHub** に2つの**非公開（Private）リポジトリ**を作る
   - `cinematierlist`（アプリ本体。このフォルダを push）
   - `tierlist-data`（データ保存用。空でOK、「Add a README」にチェック）
2. GitHub の Settings → Developer settings → **Fine-grained tokens** でトークンを作成
   - Repository access: `tierlist-data` のみ / Permissions: **Contents = Read and write**
3. （既存データを引き継ぐ場合のみ）Mac で一度だけ実行し、聞かれたらトークンを貼り付けて Enter：

   ```bash
   python3 upload_data.py
   ```

4. **Render**（render.com）に GitHub アカウントでログイン → New → **Blueprint** → `cinematierlist` を選択
   - `GITHUB_TOKEN` と `DATA_REPO`（例: `ユーザー名/tierlist-data`）を入力して作成
5. 発行された `https://cinema-tier-list-xxxx.onrender.com` を開く（スマホは「ホーム画面に追加」でアプリ化）

> - 無料枠は**15分アクセスが無いと休止**し、次に開いたとき**起動まで1分ほど**かかります。データは GitHub に保存されているので消えません。
> - URL を知っている人は誰でも開けるため、自分のアカウントを作ったら Render の環境変数 `ALLOW_REGISTER` を `0` にして**新規登録を締め切る**のがおすすめです。

### アカウントで端末間同期する（ログイン）

ヘッダーの **👤 ログイン** からアカウントを作ると、Tier List が `server.py` 側（このMac内の `data/` フォルダ）に保存され、**別の端末で同じアカウントにログインすると同じ内容を編集**できます（クラウド同期）。

- **新規登録 / ログイン**: ユーザー名（半角英数・2〜32文字）とパスワード（6文字以上）だけ。
- **自動保存**: ログイン中の変更は自動でサーバーへ保存されます。別端末では、ログイン時や「↻ 今すぐ最新を取得」で反映されます。
- **競合時**: 同じアカウントを複数端末で編集した場合は、**最後に保存された内容（新しい方）**が優先されます。
- **未ログインでも利用可**: ログインしなくても、これまで通り端末内（localStorage）に保存されます。
- **保存場所とセキュリティ**:
  - パスワードは **PBKDF2-HMAC-SHA256（ソルト付き）** でハッシュ化して保存し、平文では保存しません。
  - ログイン状態は **HMAC署名付きのHttpOnly Cookie**（30日）で保持します。
  - アカウント情報・各ユーザーのリストは `data/`（`users.json` / `secret.key` / `lists/<id>.json`）に保存されます。**このフォルダは他人に共有しないでください**（バックアップ対象にはしても、公開リポジトリ等には含めないこと）。
  - パスワードはネットワークを通るため、**外出先からのログインは Tailscale の HTTPS（`tailscale serve`）経由**での利用を推奨します（自宅LAN内の平文HTTPは同一ネットワーク前提）。

### 2. 映画を追加する

画面上部の**クイック追加バー**にタイトルを入れて Enter すると、モーダルを開かずに検索結果から次々と追加できます。じっくり探すときは「＋ 映画を追加」から各タブを使います。

- **🔍 検索して追加**: 映画タイトルで検索し、ポスターを自動取得します（Filmarks）。ポスターが欠けている作品は、バックグラウンドで自動補完されます。
- **🕰️ 年で振り返る**: 観た年（製作年）を選ぶと、その年の話題作から**ランダム**に一覧表示されます（見るたびに変わります／Filmarks 由来、約1930年〜現在）。**観た作品をタップして選び、まとめて追加**でき、下部の「もっと見る」で続きを辿れます。過去の記憶を辿るのに便利です（`server.py` が必要）。
- **✨ おすすめ**: すでに登録済みの**監督・出演者**をもとに、まだ入れていない作品を提案します。登録するほど精度が上がります（`server.py` が必要。初回はリストの分析が必要な場合があります）。
- **📚 コレクション**: スタジオジブリ・ピクサー・ハリー・ポッター・ミッション:インポッシブルなど、**人気シリーズ／名作をチェックリスト形式**でまとめて追加できます（`server.py` が必要）。
- **👥 人物でまとめて**: 俳優・監督名で検索し、その人の作品を**一括で追加**できます（`server.py` が必要）。
  - 人物を選ぶとフィルモグラフィが表示され、「出演」「監督」「脚本」などの**役割で絞り込み**できます。
  - 例: 「トム・クルーズ」→ 出演、「クリストファー・ノーラン」→ 監督 で絞り込み。
- **✍️ 手動で追加**: タイトルと、任意でポスター画像のURLまたはアップロード画像を指定します。**サーバー無しでもすぐ使えます。**

> 「🕰️ 年で振り返る」「✨ おすすめ」「📚 コレクション」は、**チェックした作品だけをまとめて追加**できるので、過去に観た作品を効率よく登録していけます。ヘッダーの **🎞️ 本数カウンター**は登録するたびに増え、節目（10・50・100本…）でお祝いが表示されます。

### 3. ランク付けする

未分類エリアの映画ポスターを、各ティア（S / A / B / C / D …）へ**ドラッグ&ドロップ**で振り分けます。同じティア内での並び替えも可能です。

### テーマで絞り込む

ボード上部の「🎯 テーマで絞り込み」で、TierList内の作品を**テーマ別に表示**できます。

- 候補は**登録済みの作品から自動生成**されます。
- **公開年**（例: 「2026年公開作品」）はそのまま選べます。
- **コレクション**（例: 「スタジオジブリ」「マーベル」）は、登録作がシリーズに該当すると自動で候補に並びます。
- **監督 / 出演者**（例: 「トム・クルーズ出演作」）は、パネル内の「監督」「出演者」タブにある **🔄 監督・出演者を取得** ボタンを押すと各作品の情報を取得し、複数作品に登場する人物が候補に並びます（`server.py` が必要。一度取得すれば保存されます）。
- 選ぶと一致しない作品が非表示になり、「すべて表示（解除）」で解除できます。

### お題にして呼びかける

テーマで絞り込んだ状態で **📣 お題にする** を押すと、その作品セットでティアリストを作ってもらうリンクを作れます（`server.py` が必要）。

- **監督・出演者・コレクション・公開年**のテーマは、自分の登録作に限らず**テーマの全作品**を Filmarks から取得して対象にできます（公開年は話題作の上位60本）。お題に合わない作品はチェックを外せます。
- タグ・ジャンル・種別・映画賞・複数条件の組み合わせは、全作品を特定できないため自分の登録作が対象です。

- 受け取った人はリンクを開き、観た作品にチェックして「このお題で作る」→ ティアに振り分けて **📨 結果を送る**。
- 集まった結果は **みんなのランキング**（平均の順位・人数・分布）と、作成者との一致度で見られます。
- 作成・参加したお題は「🌐 みんな」→「📣 お題」から開けます。データは `data/challenges/` に保存されます。

### 大量の作品を登録する場合

数千本規模でも見やすく・軽快に保つための機能があります。

- **コンパクト表示**: ⚙️ 設定の「コンパクト表示」をオンにすると、ポスターを小さくしタイトルを隠して一覧性を上げます（設定は保存されます）。
- **折りたたみ**: 各ティアの左上の「▼」や「未分類の映画」見出しの「▼」で、エリアを折りたたみ／展開できます。折りたたむと縦のスペースを節約でき、描画も軽くなります。
- **表示制限（自動）**: 1エリアに大量の作品がある場合は一定数までを表示し、「＋ さらに表示」で追加読み込みします。画面上の要素数を抑えることで、数千本でも動作が重くなりにくくなります。
- 各ティア・未分類には**登録本数**が表示されます（フィルター時は絞り込み後の件数）。

### ティアごとに分析する

各ティアの見出しの 📊（またはラベルをクリック →「このティアを分析」）で、そのティアの作品がどんな傾向かをインフォグラフィックで表示します。

- キーワード（種別・年代・特に多いジャンル）、作品数・上位何%・平均公開年・邦画/アニメの割合
- 種別・年代・ジャンル・コレクション/映画賞を「全体（ティアに振り分けた全作品）」と比べたグラフ（×1.5＝全体の1.5倍）
- 監督・出演者 TOP と、このティアに集中している人物
- 上部のタブでティアを切り替え、「画像として保存」でPNGに書き出せます

### 4. ティアをカスタマイズ

- ティアのラベル（左端の色付き部分）をクリック → **名前・色の変更、上下移動、削除**ができます。
- 「＋ ティアを追加」で行を増やせます。「ティアを初期化」で S/A/B/C/D に戻せます。

### 5. 保存・共有

- **💾 保存 ▾**: ボタンを押すとメニューが開き、2通りの保存を選べます。
  - **ファイルとして保存**: 後から**再編集できるファイル（.json）**として保存します。
  - **画像として保存**: 完成したTier ListをPNG画像として書き出します（閲覧・共有用）。
- **📂 開く**: 保存した `.json` ファイルを読み込んで、続きから編集できます。
- デザイン（スタジオ / クラシック）やコンパクト表示の切り替えは ⚙️ 設定にまとめています。設定（⚙️）には同じ「データを書き出し / 読み込み」もあります。

> ヒント: 編集内容はブラウザ内（localStorage）にも自動保存されます。別の端末やブラウザに移したいとき、バックアップを残したいときは「💾 保存」で `.json` を書き出してください。

## データの取得元について

- 作品の検索・ポスター・監督/出演・人物・公開予定などは、すべて **Filmarks** から取得します（付属サーバー `server.py` が代理取得。ブラウザから直接取得すると CORS でブロックされるため）。
- 以前のバージョンで映画.com / TMDB から追加した作品は、起動時にバックグラウンドで Filmarks の作品と照合し、ポスターを Filmarks のものに差し替えます（照合できない作品は元のポスターのまま）。
- Filmarks の公開ページを取得する仕組みのため、サイト構造が変わると解析が動かなくなる場合があります。

## 技術メモ

- 依存: ブラウザ標準API + [html-to-image](https://github.com/bubkoo/html-to-image)（CDN、PNG書き出しのみ使用）
- データ保存先: ブラウザの localStorage（端末内に保存され、外部送信されません）
- PWA対応: `manifest.webmanifest` / `sw.js`（Service Worker）/ `icon.svg`。HTTPS もしくは localhost でアクセスすると「ホーム画面に追加」で全画面アプリ化でき、オフラインでも直近の画面を開けます（検索など通信が必要な機能はオンライン時のみ）。Service Worker は **network-first**（常に最新を取得、取得できた分をキャッシュ）で、古い表示が残りにくい設計です。
- ファイル構成:
  - `index.html` — 画面構造
  - `styles.css` — スタイル
  - `app.js` — 状態管理・DnD・検索・書き出し
  - `server.py` — 静的配信＋Filmarks 代理取得API
  - `manifest.webmanifest` / `sw.js` / `icon.svg` — PWA（インストール／オフライン）

## 注意

- 外部URLのポスター画像は、配信元のCORS設定によってPNG書き出し時に読み込めない場合があります。その場合は画像をアップロードして追加するか、検索から追加し直してください。
